# 架构图

用 Mermaid 写的图，GitHub 和 Notion 里直接显示，改代码时顺手改这里。配合 [`回放.html`](回放.html)（双击打开，看一次真实运行的数据流）一起看。

## 1. 谁依赖谁

只能自上而下依赖。`control` 不碰串口，`driver` 不知道轨迹和保护。

```mermaid
flowchart TB
    app["你的程序 / tools/ui.py / tools/tune.py"]
    subgraph control["neck.control（层 2：安全运动）"]
        neck["Neck<br/>唯一入口，phase 状态机"]
        traj["Trajectory<br/>限位 限速 限加速 平滑<br/>纯数学"]
        sup["Supervisor<br/>level 0/1/2/3<br/>纯判断"]
    end
    subgraph driver["neck.driver（层 1：硬件）"]
        dev["Driver<br/>两轴 DriverState 串口扫描 失败回滚"]
        motor["Motor<br/>单轴 命令间隔 查询重试"]
        proto["protocol<br/>组帧 解析 BCC 角度折叠"]
        port["Port<br/>termios 串口 截止时间 十六进制日志"]
    end
    bus["TTL 串口<br/>yaw=ID1  pitch=ID2"]
    app --> neck
    neck --> traj
    neck --> sup
    neck -->|"enable set set_zero save read disable close state"| dev
    dev --> motor --> proto
    motor --> port --> bus
```

## 2. 一个 tick 里发生什么

上层每 20–33 ms 调一次 `tick()`。

```mermaid
sequenceDiagram
    participant U as 上层
    participant N as Neck
    participant S as Supervisor
    participant T as Trajectory
    participant D as Driver
    participant M as 电机

    U->>N: set_target(yaw, pitch)
    Note over N: 限位后记为目标，phase 变 following
    U->>N: tick()
    N->>S: 距上次 tick 多久
    S-->>N: 正常 / level 1 / level 3
    N->>D: read(0.08 s)
    D->>M: 查询机械角（两轴各一次）
    M-->>D: 反馈帧
    D-->>N: Pose（折到 -180..180）
    N->>S: 反馈老不老 / 停滞 / 摆动
    S-->>N: 无事 / level 1 / level 2
    N->>T: step(now)
    T-->>N: 下一条安全指令
    N->>N: 指令领先实测超过 18 度则暂停推进
    N->>D: set(变化的轴)
    D->>M: 目标角帧（yaw 后 pitch，帧间隔 8 ms）
    N-->>U: Snapshot（phase level reason 三个角度）
```

## 3. 使能与回零

```mermaid
sequenceDiagram
    participant N as Neck
    participant D as Driver
    participant M as 电机

    N->>D: read()
    D-->>N: 当前位姿 P
    N->>D: enable(P)
    D->>M: 先失能，再下发两轴 PI
    D->>M: 逐轴 使能 → 选 0004 模式 → 速度 → 目标 P → 加速度
    Note over D: 任何一步失败：失能两轴并抛错，DriverState 回 OPEN 或 UNKNOWN
    N->>N: move_to(0, 0)，phase = moving
    loop 每个 tick
        N->>D: set(沿轨迹的下一点)
    end
    Note over N: 实测在 1 度内并稳定 0.5 s → phase = hold，reason = target_reached
```

## 4. 写零位（两轴）

```mermaid
sequenceDiagram
    participant U as UI
    participant N as Neck
    participant D as Driver
    participant M as 电机

    U->>N: set_zero()
    N->>N: 只允许 off 或稳定的 hold
    N->>D: read()
    N->>D: set_zero()
    D->>M: yaw 零点帧 0x0A
    D->>M: yaw 目标 0.0（使能时立刻改瞄）
    D->>M: pitch 零点帧 0x0A
    D->>M: pitch 目标 0.0
    N->>D: read() 读回
    alt 两轴都在 ±0.5 度内
        N->>D: save()
        D->>M: 保存帧 0x08（两轴）
        N-->>U: reason = zero_saved
    else 读不回或偏差大
        N->>D: disable()
        N-->>U: NeckError zero_verify_failed
    end
```

## 5. Neck 的状态（phase）

```mermaid
stateDiagram-v2
    [*] --> off
    off --> enabled: enable 然后回零
    enabled --> off: disable
    enabled --> fault: level 3 或使能失败，已失能并锁存
    fault --> off: disable 成功后 reset_fault
    state enabled {
        [*] --> moving
        moving --> hold: 实测到位并稳定
        hold --> moving: move_to
        hold --> following: set_target
        moving --> following: set_target
        following --> stale: 0.2 s 没有新目标 或 may_send 为假
        stale --> following: set_target
        following --> hold: hold
        hold --> degraded: level 2
        degraded --> hold: 稳定 0.3 s 后回到进入前的 phase
    }
    note right of enabled
        moving 和 following 遇到 level 2 同样进入 degraded
        恢复后回到原来的 phase
    end note
```

## 6. Driver 的状态（DriverState）

```mermaid
stateDiagram-v2
    [*] --> OPEN: Driver.open
    OPEN --> ARMED: enable 成功
    ARMED --> OPEN: disable 成功
    ARMED --> UNKNOWN: 失能帧发不出去
    OPEN --> UNKNOWN: 失能帧发不出去
    UNKNOWN --> OPEN: disable 重试成功
    OPEN --> CLOSED: close
    ARMED --> CLOSED: close（先失能）
    UNKNOWN --> UNKNOWN: close 失败，端口已释放
```

## 7. 保护分级

```mermaid
flowchart LR
    ok["level 0 正常"]
    l1["level 1 扰动<br/>本 tick 暂停，不失能"]
    l2["level 2 降级<br/>保持使能，指令拉回实测，等稳定"]
    l3["level 3 故障<br/>失能并锁存"]
    ok -->|"tick 间隔 0.1 到 1 s<br/>读失败但反馈仍新<br/>保持位振荡"| l1
    ok -->|"反馈老于 0.1 s<br/>某轴停滞 1.5 s"| l2
    ok -->|"反馈丢失 0.5 s 以上<br/>tick 间隔 1 s 以上<br/>写失败 移动超时 15 s"| l3
    l1 -->|"30 s 内累计 6 次"| l3
    l2 -->|"持续 5 s"| l3
    l1 -->|"下个 tick 正常"| ok
    l2 -->|"误差 3 度内稳定 0.3 s"| ok
    l3 -->|"disable 成功后 reset_fault"| ok
```
